/***********************************************************************************************************************
* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F51138AxFP
* Tool-Chain              : IAR Systems ICCRX
* Development environment : IAR Embedded Workbench
* Version                 : Code Generator for RX113 V1.01.00.02 [31 Jul 2014]
* H/W Platform            : RSKRX113 with RSK LCD APP V2 
*
* Description  : Sample application configured to be loaded via the System BootLoader.
*
* Configuration:
*             Links & Jumpers: Set to default configuration shown in RSK User's Manual.
*
* Note	       : This sample has been configured to run with the System_BootLoader.
*                The build process will produce a S-Record image in the HardwareDebug or Release
*                directory (depending on the build configuration selected).
*
* Operating Procedure:  
*    For details of Building and Downloading the sample code refer to  the RSK Tutorial Manual.
*
*          1. Attach the E1 debugger to the RSK.
*
*         (Launching via BootLoader)
*	       ----------------------
*	      2a. Build the sample.
*	
*	      2b. Follow the instructions for the System_BootLoader and send the 'System_BootLoader_Application.mot'
*            file contained within this sample's HardwareDebug or Release folder (depending on build 
*	         configuration selected)
*
*          (Launching via E1 Emulator)
*	       ----------------------
*	      3a. Connect the RSK RL78G1C-USB port to a PC using a USB Type A to mini B cable.
*	      The first time this port is connected to the PC an 'Installing Device Driver Software'
*	      pop-up will appear and the driver will be automatically installed. In Device Manager, the virtual
*	      COM port will appear under 'Port (COM & LPT)' as 'RSK USB Serial Port (COMx)', 
*                
*	      3b. Open a terminal program (e.g HyperTerminal) on the virtual COMx port created in step 1. 
*	      Ensure the terminal program connection settings are as follows:
*                
*                Baud Rate.............38400
*                Data Bits.................8
*                Parity.................None
*                Stop Bits.................1
*                Flow Control...........None
*
*	      3c. Build and download the sample code. 
*	      This sample is configured to run via the boot loader, the Start address is not
*	      automatically detected by the IDE so the initial Program Counter must be set 
*	      manually.
*
*	      Select: Window -> Show View -> Registers. Click the arrow next to 'General Registers'.
*	      Locate the 'pc' register and change the value to: 0xFFF85000 (location of PowerON_Reset).
*		 
*
*	      3d. Click the 'Resume' button to start program execution.
*	      Click the 'Resume' button again if the program stops at main().
*
*
*	      (Sample Execution)
*	      -----------------
*
*	      4. The word 'DEMO' will scroll across the bottom line of the LCD.
*
*	      5. Pressing SW3 will toggle LED0, LED1, LED2 and LED3.
*
*	      6. The terminal window will display a welcome banner and instructions.
*	      Entering the character 'z' in the terminal will toggle LED0, LED1, LED2 and LED3.
*
*
***********************************************************************************************************************/
