* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F51138AxFP
* Tool-Chain              : IAR Systems ICCRX
* Development environment : IAR Embedded Workbench
* Version                 : Code Generator for RX113 V1.01.00.02 [31 Jul 2014]
* H/W Platform            : RSKRX113 with RSK LCD APP V2  
*
* Description  : This sample uses MTU4 to output a 1KHz PWM square waveform on the MTIOC4A output pin.
*
* Configuration:
*             Links & Jumpers: Set to default configuration shown in RSK User's Manual.
*
* Operating Procedure:  
*    For details of Building and Downloading the sample code refer to  the RSK Tutorial Manual.
*
*                 1. Attach the E1 debugger to the RSK.
*
*				  2. Connect an oscilloscope probe to JA2, pin 15. 
*
*                 3. Build and download the sample code. Click the 'Resume' button to start program execution.
*                    Click the 'Resume' button again if the program stops at main().
*
*                 4. A 1KHz PWM output increasing from 10% to 90% then stepping
*                    back to 10% will be displayed on the oscilloscope. The 
*                    signal can also be seen on LED2.
*
*                 5. Press SW1 to stop the duty cycle modulation and display 
*                    the duty as a percentage. Observe the static waveform on 
*                    the oscilloscope.
*
*                 6. Press SW1 again to continue duty cycle modulation. Observe the  
*                    waveform's duty cycle varying.
***********************************************************************************************************************/
