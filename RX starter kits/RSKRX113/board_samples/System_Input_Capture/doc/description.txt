/***********************************************************************************************************************
* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F51138AxFP
* Tool-Chain              : IAR Systems ICCRX
* Development environment : IAR Embedded Workbench
* Version                 : Code Generator for RX113 V1.01.00.02 [31 Jul 2014]
* H/W Platform            : RSKRX113 with RSK LCD APP V2 
*
* Description  : System Input Capture sample application.
*                This application logs time, temperature and an ADC reading into Non Volatile storage
*                and allows data retrieval via the SCI to a terminal program.  Data is stored in 
*                fixed length 16 byte records in internal IIC EEEPROM.  
*                Each record is stored at a regular interval as determined by the Real-time clock (RTC)
*                constant period interrupt.  This may be set to either 1 second or 2 second
*                by user switch presses.  The sample application will send the RX113 into software standby mode,
*                being woken by the RTC periodic interrupt.
*                Data may be retrieved or erased from the non volatile memory by the virtual COM port.
*
* Note         : Code Generator is used to generate code for this sample program. 
*                The Code Generator details and version number are given in the file 
*                header for each relevant module.
*
* Configuration:
*             Links & Jumpers: Set to default configuration shown in RSK User's Manual.
* 
*                External Device/Component
*                -------------------------
*                This sample is configured to look for the on-board IIC EEPROM at IIC address 0xA0
*                and if found, the sample uses this EEPROM for Non Volatile Memory (NVM) storage.
*                Works with the Renesas R1EX24xxx series, 16Kbit EEPROM and compatible devices. 
*                The size of the EEPROM is defined in the file r_rsk_iic_eeprom.h and may be changed by editing
*                line 44:          #define IIC_EEPROM_SIZE_BYTES 2048
*                The RSKRX113 is shipped with the EEPROM connected by default.
*                To disable the on board EEPROM and use RX113 data flash for NVM, remove R6 and R7.
*
* Operating Procedure:  
*    For details of Building and Downloading the sample code refer to  the RSK Tutorial Manual.
*
*             1. Attach the E1 debugger to the RSK.
* 
*             2. Connect the RSK G1CUSB0 port to a PC using a USB Type A to mini B cable.
*                The first time this port is connected to the PC an 'Installing Device Driver Software'
*                pop-up will appear and the driver will be automatically installed. In Device Manager, the virtual
*                COM port will appear under 'Port (COM & LPT)' as 'RSK USB Serial Port (COMx)', 
*                where x is a number.
*                
*             3. Open a terminal program (e.g HyperTerminal) on the virtual COMx port created in step 1. 
*                Ensure the terminal program connection settings are as follows:
*                
*                Baud Rate.............19200
*                Data Bits.................8
*                Parity.................None
*                Stop Bits.................1
*                Flow Control...........None
*
*             4. Build the sample code and download to the RSK. 
*				 Click the 'Resume' button to start program execution.
*                Click 'Resume' again if the program stops at main().
*
*             5. A real time clock will be displayed on lines 1 and 2 of the LCD
*                The clock is updated when the device is in normal operating mode.
*                The bottom line shows the hex value of the potentiometer RV1.
*
*             6. The interval at which data is captured and logged defaults to 1-second, and may be changed as follows:
*				 Pressing SW3 - 2-second interval.
*				 Pressing SW2 - 1-second interval.
*          
*             7. Rotate the potentiometer RV1 slowly and observe the displayed hex value vary.
*
*             8. Pressing 'R' or 'r' in the terminal window results in all the data stored in NVM to be sent to 
*				 the terminal in a readable .csv format.  This data may copied from the terminal and saved to a .csv file 
*                for later importing into Microsoft Excel or a similar spreadsheet application.
*          
*             9. Pressing 'E' or 'e' in the terminal window will perform a full erase of the NVM and data 
*				 logging will immediately be resumed. Should the NVM become full, the logging will restart from 
*				 the first address.
***********************************************************************************************************************/
