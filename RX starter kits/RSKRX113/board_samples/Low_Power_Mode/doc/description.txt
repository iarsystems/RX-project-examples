/***********************************************************************************************************************
* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F51138AxFP
* Tool-Chain              : IAR Systems ICCRX
* Development environment : IAR Embedded Workbench
* Version                 : Code Generator for RX113 V1.01.00.02 [31 Jul 2014]
* H/W Platform            : RSKRX113 with RSK LCD APP V2 
*
* Description  : This sample demonstrates usage of low power modes, using
*                RSK SW2 to send the RSK into one of the three power down modes.
*
*                The power down modes are:
*                                   Sleep Mode
*                                   Deep Sleep Mode
*                                   Software Standby Mode
* 
*            Sleep and Deep Sleep modes have peripherals operating and be running with ICLK = 32MHz.
*
* Configuration:
*           Links & Jumpers: 
*                Change from default configuration shown in RSK User's Manual:
*                Remove R221 and connect an ammeter across J11, configure the ammeter for current measurement.
*                Do not use the autorange function on the ammeter, as this may cause large resistive loads to be 
*                inserted in the power supply to the microcontroller.
*                Having and E1 attached will affect the current measurement. Accurate current measurements may be 
*                achieved by programming the RSK using the E1, removing the E1 and powering the RSK with an
*                external, center positive, 5v power supply attached to the PWR connector.
*                
*                
* Operating Procedure:  
*    For details of Building and Downloading the sample code refer to  the RSK Tutorial Manual.
*
*                 1. Attach the E1 debugger to the RSK.
*
*                 2. Build and download the sample code. Click the 'Resume' button to start program execution.
*                    Click 'Resume' again if the program stops at main().
*                    Press 'Stop' and disconnect the debugger from the RSK E1 connector. 
*                
*                 3. The LCD will display "NORM" and will not be in a low power mode.
*
*                 4. Press SW2, to set the MCU into sleep mode. The LCD will 
*                    display "SLP".
*
*                 5. Press SW2, to set the MCU into deep sleep mode. The LCD will 
*                    display "DSLP".
*
*                 6. Press SW2, to set the MCU into software standby mode. The LCD will 
*                    display "SSBY".
*
*                 7. Press SW2 to wakeup from the software standby mode. The LCD will 
*                    display "NORM".
*
***********************************************************************************************************************/
