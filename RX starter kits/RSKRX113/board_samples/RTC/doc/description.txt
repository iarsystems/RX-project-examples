*       Links & Jumpers: Set to default configuration shown in RSK User's Manual.
*
* Operating Procedure:  
*    For details of Building and Downloading the sample code refer to  the RSK Tutorial Manual.
*
*             1. Attach the E1 debugger to the RSK.
* 
*             2. Build and download the sample code. Click the 'Resume' button to start program execution.
*                Click 'Resume' again if the program stops at main().
*                
*             3. Observe the 12-hour digital clock on the LCD. At 12:00:00am the alarm interrupt will be activated and
*                'ALARM' will be shown on the LCD. LED1 will also illuminate  for a period of up to 
*                30 seconds or until switch SW1 is pressed.
