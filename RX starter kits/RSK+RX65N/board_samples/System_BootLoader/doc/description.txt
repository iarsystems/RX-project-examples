/***********************************************************************************************************************
* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F565N9AxFB
* Tool-Chain              : CC-RX V2.05.00
* Development environment : Renesas e2 studio
* Version                 : Code Generator for RX65N V1.00.00.08 [25 Aug 2016]
* H/W Platform            : RSK+RX65N
* 
* Description  : Demonstrates of flash programming and user code update via virtual serial port.
*
* Configuration:
*             Links & Jumpers: Set to default configuration shown in RSK+ User's Manual.
*
* Note         : 1) This sample uses X-Modem to transfer the user program to the RSK+RX65N. 
*                   X-Modem cancel packet is used to abort a transfer if any errors are detected. This feature is 
*                   not implemented in all terminal programs, HyperTerminal is an example that does support this.
*
*                2) User applications programmed by the boot loader must be configured differently to standard
*                   samples to run correctly. 
*                   The System_BootLoader_Application is pre-configured to work with the boot loader.
*                   Please refer to the Bootloader Application Note - R20AN0392EG for further details.
*
* Operating Procedure:
*                For details of Building and Downloading the sample code refer to the RSK+RX65N Tutorial Manual 
*                (r20ut3562eg0100-rsk+rx65n-tutorialmanual.pdf).
*
*             1. Attach the E2 Lite debugger to the RSK+.
*
*             2. Connect the RSK+'s G1CUSB0 port to a PC using a USB Type A to mini B cable. The first time this port
*                is connected to the PC an 'Installing Device Driver Software' pop-up will appear and the driver will be
*                automatically installed. In Device Manager, the virtual COM port will appear under 'Port (COM & LPT)'
*                as 'RSK USB Serial Port (COMx)', where x is a number.
*
*             3. Open a terminal program (e.g HyperTerminal) on the virtual COMx port created in step 1. 
*                Ensure the terminal program connection settings are as follows:
*
*                Baud Rate.............38400
*                Data Bits.................8
*                Parity.................None
*                Stop Bits.................1
*                Flow Control...........None
*
*             4. Build and download the sample code. Click the 'Resume' button to start program execution.
*                Click the 'Resume' button again if the program stops at main().
*
*             5. On the first execution the terminal instructions will request an application image via X-modem.
*                Use the terminal program to send an S-Record (.mot) image file to the boot loader
*                using the X-Modem transfer protocol.
*
*                After a successful transfer the flash will be updated and the user will be prompted to press SW2 to
*                launch the application.
*
*                If an error occurred during the transfer or flash writing, the user will be prompted to reset and
*                retry.
*
*             6. If an application has been previously programmed, the boot loader will skip the download and prompt
*                to press SW2 to launch the application.
*
*                To force the boot loader download a new image, press and hold SW1 during boot loader startup.
*
*             Note: The E2 Lite debugger will overwrite flash areas during download. This will invalidate any previously
*             downloaded application and the boot loader will always prompt to re-download the user application.
*
***********************************************************************************************************************/
