/***********************************************************************************************************************
* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F565N9AxFB
* Tool-Chain              : CC-RX V2.05.00
* Development environment : Renesas e2 studio
* Version                 : Code Generator for RX65N V1.00.00.08 [25 Aug 2016]
* H/W Platform            : RSK+RX65N
*
* Description  : Sample application configured to be loaded via the System BootLoader.
*
* Configuration:
*             Links & Jumpers: Set to default configuration shown in RSK+ User's Manual.
*
* Note         : This sample has been configured to run with the System_BootLoader.
*                The build process will produce a S-Record image in the HardwareDebug or Release
*                directory (depending on the build configuration selected).
*
* Operating Procedure:  
*                For details of Building and Downloading the sample code refer to the RSK+RX65N Tutorial Manual 
*                (r20ut3562eg0100-rsk+rx65n-tutorialmanual.pdf).
*
*          1. Attach the E2 Lite debugger to the RSK+.
*
*         (Launching via BootLoader)
*           ----------------------
*             2a. Build the sample.
*
*             2b. Follow the instructions for the System_BootLoader and send the 'System_BootLoader_Application.mot'
*                 file contained within this sample's HardwareDebug or Release folder (depending on build 
*                 configuration selected)
*
*         (Launching via E2 Lite Emulator)
*            ----------------------
*             3a. Connect the RSK+'s G1CUSB0 port to a PC using a USB Type A to mini B cable. The first time this port
*                is connected to the PC an 'Installing Device Driver Software' pop-up will appear and the driver will be
*                automatically installed. In Device Manager, the virtual COM port will appear under 'Port (COM & LPT)'
*                as 'RSK USB Serial Port (COMx)', where x is a number. 
*
*             3b. Open a terminal program (e.g HyperTerminal) on the virtual COMx port created in step 1.
*                 Ensure the terminal program connection settings are as follows:
*
*                 Baud Rate.............38400
*                 Data Bits.................8
*                 Parity.................None
*                 Stop Bits.................1
*                 Flow Control...........None
*
*             3c. Build and download the sample code. 
*                 This sample is configured to run via the boot loader, the Start address is not automatically detected
*                 by the IDE so the initial Program Counter must be set manually.
*
*                 Select: view -> Register. Locate the 'pc' register and change the value to: 0xffffd3c8 (location of __iar_program_start).
*
*             3d. Click the 'Resume' button to start program execution.
*                 Click the 'Resume' button again if the program stops at main().
*
*         (Sample Execution)
*         -----------------
*
*             4. Pressing SW1 will toggle LED0, LED1, LED2 and LED3.
*
*             5. The terminal window will display a welcome banner and instructions.
*                Entering the character 'z' in the terminal will toggle LED0, LED1, LED2 and LED3.
*
***********************************************************************************************************************/
