/***********************************************************************************************************************
* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F572TKCxFB
* Tool-Chain              : CC-RX V3.01.00
* Development environment : Renesas e2 studio
* Version                 : Renesas Smart Configurator V2.1.0
* H/W Platform            : RSKRX72T
*
* Description  : Demonstrates the low power modes SLEEP, DEEP SLEEP and SW STANDBY for reducing current consumption.
*                
*                NORMAL - Normal operation with peripheral operation and all clocks running.
* 
*                SLEEP - In sleep mode, the CPU stops operating but the contents of its internal registers are retained.
*                Other peripheral functions do not stop.
*                When the WDT is used, the WDT stops counting when sleep mode is entered.
*                
*                SW STANDBY - In this mode, the CPU, on-chip peripheral functions, and the oscillator functions stop.
*                However, the contents of the CPU internal registers, RAM data, on-chip peripheral functions,
*                and the states of the I/O ports are retained.
*
*                DEEP SW STANDBY - in deep software standby mode, the CPU, internal peripheral modules (except for parts 
*                of the USB suspend/resume detecting unit), 
*                RAM, expansion RAM, and functions of the oscillators are stopped; furthermore, since the internal  
*                supply of power for these modules is stopped, power consumption is markedly reduced. Yet, the main and 
*                sub clock oscillators can be operated or stopped. Entering and Exiting Low Power Consumption Modes and 
*                Operating States in Each Mode. At this time, the contents of all the registers of the CPU and internal 
*                peripheral modules (except for parts of the USB suspend/resume detecting unit) become undefined.
*
* Note         : Smart Configurator is used to generate code for this sample program.
*                The Smart Configurator details and version number are given in the file 
*                header for each relevant module.
*
* Operating Conditions:
*                External Device/Component
*                -------------------------
*                Remove R127 and connect an ammeter across J11, configure the ammeter for current measurement.
*                NOTE: Use of the ammeter autorange function may cause large resistive loads to be
*                inserted in the power supply to the microcontroller, causing CPU under voltage on the supply rails
*                and a reset when the MCU comes out of SLEEP mode. For this reason, do not use the ammeter autorange
*                function and be sure to switch the ammeter back to the mA range before coming out of SLEEP mode.
*
* Operating Procedure:
*                For details of Building and Downloading the sample code refer to the RSKRX72T Tutorial Manual 
*                (r20ut4276eg0100-rskrx72t-tutorialmanual.pdf).
*
*             1. Compile and download the sample code. Click the 'Resume' button to start program execution.
*                Click 'Resume' again if the program stops at main().
*                Press 'Stop' and disconnect the debugger from the RSK.
*
*             2. The hardware platform and sample name will be displayed in the first two lines of the LCD display.
*                'Normal Mode' will be displayed on the 4th line of the LCD display.
*
*             3. The sample code will cycle through the different operating modes on each 
*                switch press starting with Normal, SLEEP, Normal, SW STANDBY, Normal then DEEP SW STANDBY. 
*
*             4. Press SW1 to enter SLEEP mode, 'Sleep Mode' will be displayed on the LCD. (*1)
*                Observe the current for SLEEP mode.  Press SW1 again to return to Normal mode.
*
*             5. Press SW1 to enter SW STANDBY mode, 'SW Standby Mode' will be displayed on the LCD. (*1)
*                Observe the current for SW STANDBY mode.  Press SW1 again to return to Normal mode.
*
*             6. Press SW1 to enter DEEP SW STANDBY mode, 'Deep SW Standby Mode' will be displayed on the LCD. (*1)
*                Observe the current for DEEP SW STANDBY mode. 
*
*             7. Press RESET to exit DEEP SW STANDBY  mode and go to step 2 to repeat the test.
*
*           (*1) By performing the following steps for get accurate reading values.
*
*             a. Disconnect the debugger from the RSK.
*
*             b. Set the jumpers of the RSK as follows.
*                J8 1-2 connected
*                J9 1-2 connected
*
*             c. Disconnect LCD display and connect 5V power from the RSK.
*
*             d. Add current ranges for NORMAL, SLEEP, SW STANDBY, DEEP SW STANDBY in hardware manual so that 
*                it can be compared with recoded reading. 
*
*             Current Reading after removing LCD display:
*
*                NORMAL: 24.0 mAmp
*                SLEEP: 12.5 mAmp
*                SW STANDBY: 0.95 mAmp
*                DEEP SW STANDBY: 0.04 mAmp
*
***********************************************************************************************************************/
