/***********************************************************************************************************************
* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F566TEAxFP
* Tool-Chain              : CC-RX V3.00.00
* Development environment : Renesas e2 studio
* Version                 : Renesas Smart Configurator V1.5.0
* H/W Platform            : RSKRX66T
*
* Description  : Demonstration of the SCI in asynchronous mode. The program communicates from the RX66T 
*                to a terminal program via an SCI channel and RS-232 via the on-board virtual USB COM port.
*
* Note         : Smart Configurator is used to generate code for this sample program.
*                The Smart Configurator details and version number are given in the file 
*                header for each relevant module.
*
* Operating Procedure:  
*                For details of Building and Downloading the sample code refer to the RSKRX66T Tutorial Manual 
*                (r20ut4154eg0100-rskrx66t-tutorialmanual.pdf).
*
*             1. Connect the RSK's G1CUSB0 port to a PC using a USB Type A to mini B cable. The first time this port
*                is connected to the PC an 'Installing Device Driver Software' pop-up will appear and the driver will be
*                automatically installed. In Device Manager, the virtual COM port will appear under 'Port (COM & LPT)'
*                as 'RSK USB Serial Port (COMx)', where x is a number.
*                
*             2. Open a terminal program (e.g HyperTerminal) on the virtual COMx port created in step 1. 
*                Ensure the terminal program connection settings are as follows:
*                
*                Baud Rate.............19200
*                Data Bits.................8
*                Parity.................None
*                Stop Bits.................1
*                Flow Control...........None
*
*             3. Compile and download the sample code. Click the 'Resume' button to start program execution.
*                Click the 'Resume' button again if the program stops at main().
*                The LCD display will show 'Asynchronous Serial Comms'.
*                
*             4. Observe the output on the terminal window. The numbers 0
*                to 9 will appear repeatedly. Type 'z' (lowercase) into the
*                terminal to pause the number outputs, and any other key to
*                resume.
*                
*             5. While data is being transmitted, LED0 will be ON and LED1 will be OFF. 
*                When transmission is inactive, LED0 will be OFF and LED1 will be turned ON.
*
***********************************************************************************************************************/
