* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F566TEAxFP
* Tool-Chain              : CC-RX V3.00.00
* Development environment : Renesas e2 studio
* Version                 : Renesas Smart Configurator V1.5.0
* H/W Platform            : RSKRX66T
*
* Description  : This sample uses channel 1 of the MTU9 to output a 1KHz PWM 
*                square waveform on the MTIOC9B output pin. 
*
* Note         : Smart Configurator is used to generate code for this sample program.
*                The Smart Configurator details and version number are given in the file 
*                header for each relevant module.
*
* Operating Procedure:  
*                For details of Building and Downloading the sample code refer to the RSKRX66T Tutorial Manual 
*                (r20ut4154eg0100-rskrx66t-tutorialmanual.pdf).
*
*             1. Connect an oscilloscope probe to 'J1.Pin17'. 
*
*             2. Compile and download the sample code. Click the 'Resume' button to start program execution.
*                Click the 'Resume' button again if the program stops at main().
*
*             3. A 1KHz PWM output increasing from 10% to 90% then stepping
*                back to 10% will be displayed on the oscilloscope.
*                The signal can also be seen on LED3.
*
*             4. Press SW1 to stop the duty to cycle modulation and display the duty as a percentage.
*                Observe the static waveform on the oscilloscope.
*
*             5. Press SW1 to continue duty to cycle modulation. Observe the waveform's duty cycle varying.
*
***********************************************************************************************************************/
