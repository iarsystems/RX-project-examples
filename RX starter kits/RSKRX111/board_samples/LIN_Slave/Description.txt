/***********************************************************************************************************************
* File Name     : Description.txt
* Version       : Application Leading Tool (Applilet) for RX111 V1.00.00.05 [06 Jun 2013]
* Device(s)     : R5F51115AxFM
* Tool-Chain    : CCRX
* H/W Platform  : RSKRX111
* Description   : Demonstration of SCI12 module in LIN Master mode.
*                 The SCI12 has extended serial mode features that are
*                 applicable to the LIN SYNC BREAK and SYNC frame structure.
* Note          : Application Leading Tool (Applilet) is used to generate code 
*                 for this sample program.  The name Applilet is used hereafter.
*                 The Applilet details and version number are given in the file 
*                 header for each relevant module.
* Operation     : Before starting, ensure the RSK is connected to another RSK 
*                 that is running the LIN_Slave sample:
*                
*                 Wire Connections
*                 ----------------
*                 a. LIN pin no.1 (VBAT) <---> LIN pin no.1 (VBAT)
*                 b. LIN pin no.2 (LIN) <---> LIN pin no.2 (LIN)
*                 c. LIN pin no.3 (GND) <---> LIN pin no.3 (GND)
*                 
*                 In addition, it is necessary to power the RSK from a +5V
*                 centre positive PSU via the PWR connector.
*
*                 Resistors
*                 ---------
*                 Remove R151 and R161.
*
* Instructions : 
*                 1. Compile the sample code, and download to the RSK. Click the 'Go' 
*                    button to start program execution.
*                 2. Adjust the potentiometer on the slave RSK. The ADC value 
*                    will be displayed on the slave LCD and transmitted to this
*                    board, where it will also be displayed on the LCD.
*                 3. The ADC result displayed on the LCD connected to Master
*                    RSK and Slave RSK should match. Data transmission is 
*                    checksum protected and if the LIN master detects a checksum
*                    error the master LCD will display CS_FAIL in the LCD. If
*                    this occurs check the connection between the boards and
*                    restart both RSKs.           
*                   
***********************************************************************************************************************/
