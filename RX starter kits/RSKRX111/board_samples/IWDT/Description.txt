/***********************************************************************************************************************
* File Name     : Description.txt
* Version       : 1.0
* Device(s)     : R5F51115AxFM
* Tool-Chain    : CCRX
* H/W Platform  : RSKRX111
* Note          : Application Leading Tool (Applilet) is used to generate code 
*                 for this sample program.  The name Applilet is used hereafter.
*                 The Applilet details and version number are given in the file 
*                 header for each relevant module.
* Description   : This sample demonstrates usage of the independent watchdog 
*                 timer, by configuring the timer to require periodic resets to
*                 prevent a timer underflow. The sample configures a periodic
*                 timer reset which has a period that varies with the position
*                 of the potentiometer, RV1. The LEDs flash to indicate each
*                 period.
* Operation     : 
*                 1. Ensure the potentiometer, RV1, is turned to the fully anti-
*                    clockwise position before starting the sample. 
*                   
*                 2. Compile and download the sample code. Click the 'Debug Icon' 
*                    button to start program execution. Click 'Resume' if the 
*                    program stops at Main.
*
*                 3. The Pmod display will display the sample name, and the user
*                    LEDs will begin to flash.
*                   
*                 4. Slowly turn the potentiometer RV1 clockwise, and observe 
*                    the gradual decrease of the LED flash rate. Each time the
*                    LEDs toggle output state, the independent watchdog timer is
*                    refreshed, preventing it from underflowing which would 
*                    cause a system reset.
*                   
*                 5. Continue to turn the potentiometer clockwise - the LED
*                    flashing will slow down to a point where the independent 
*                    watchdog timer is allowed to underflow.  At this point a
*                    system reset will occur and the program will restart, but 
*                    this time it will display the message:
*                                   "  IWDT  " 
*                                   "Underflow".
*                     All the LEDs will be turned ON.
*                   
*                 7. To repeat the sample, ensure RV1 is fully anti-clockwise,
*                    click 'Suspend' and then click 'Restart'. Click 'Resume' 
*                    if the program stops at Main.
**                
***********************************************************************************************************************/
