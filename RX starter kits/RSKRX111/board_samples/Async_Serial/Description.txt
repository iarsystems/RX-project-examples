/*******************************************************************************
* File Name     : Description.txt
* Device        : R5F51115AxFM
* Tool-Chain    : RX Family C Compiler 1.2.1.0
* H/W Platform  : RSKRX111
* Note          : Application Leading Tool (Applilet) is used to generate code 
*                 for this sample program.  The name Applilet is used hereafter.
*                 The Applilet details and version number are given in the file
*                 header for each relevant module.
* Description   : Demonstration of SCI in asynchronous mode. The program 
*                 communicates from the RX111 to a terminal program via SCI and
*                 RS-232.     
* Instructions  : Note that it is important to perform the following steps in the
*                 correct sequence or there may be issues encountered where the
*                 serial-USB connection fails to be established correctly.
*
*                 1. Build the sample code. If external power is to be 
*                    used then apply the power first. If in debug mode start  
*                    a debug session which leaves the RSK board powered up. Do not run
*                    the application at this stage.  
*  
*                 2. Connect the RSK board to the PC via mini USB socket RL78G1C-USB.
*                    
*                 3. Start a PC running terminal emulator (e.g. hyperterminal).
*                    Select the appropriate COM port and set the parameters as: 
*
*                               Baud Rate:      19200
*                               Data Bits:      8
*                               Parity:         None
*                               Stop Bits:      1
*                               Flow Control:   None
*
*
*                 4. If using E1 emulator, run the program otherwise press  
*                    the reset button.
*                    
*                 5. Observe the output on the terminal window. Some introduction
*                    text will be displayed followed by the numbers 0 to 9 
*                    appearing repeatedly. Type 'z' (lowercase) into the
*                    terminal to pause the UART writes, and any other key to
*                    resume.
*
*                 6. While data is being transmitted, LED0 will be on and LED1
*                    will be off. When transmission is inactive, LED1 will be
*                    on and LED0 will be off. 
*******************************************************************************/
