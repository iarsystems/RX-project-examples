/***********************************************************************************************************************
* File Name    : Description.txt
* Version      : 1.0
* Device(s)    : R5F51115AxFM
* Tool-Chain   : CCRX
* H/W Platform : RSKRX111
* Note         : Application Leading Tool (Applilet) is used to generate code 
*                for this sample program.  The name Applilet is used hereafter.
*                The Applilet details and version number are given in the file 
*                header for each relevant module.
* Description  : Demonstrates usage of IIC unit in master mode, by reading and
*                writing to internal EEPROM memory or external board emulating  
*                a slave device. The address for internal EEPROM is 0xA0, and  
*                external device is 0x60.
*
*                For connection to external device, follow the instructions in 
*                I2C_Slave sample.
*                 
* Operation    : 
*                 1. Compile and download the sample code. Click the 'Debug Icon' 
*                    button to start program execution. Click again if the program
*                    stops at Main.
*
*                 2. The Pmod LCD will display "IIC Master, followed by the 
*                    following instructions:
*
*                           SW1 = Int/Ext
*                           SW2 = Write
*                           SW3 = Read
*
*                 3. Line 2 of the displays shows the operating mode, in this case: 
*                                   "Internal (0xA0)".
*
*                 4. Press switch SW2 to perform a write operation. If the write
*                    is successful, the data identifier will be displayed on the
*                    screen. Re-press SW2 to write next data.
*                
*                 5. Press switch SW3 to perform a read operation. If the read 
*                    is successful, the identifier of the data read will appear
*                    on the debug LCD.  Note: the read operation will read the 
*                    last data written.
*                    
*                 6. If a write error occurs, "Write error" will be displayed on 
*                    the Pmod LCD and if a read error occurs, "Read Error" will be 
*                    displayed on the Pmod LCD.
*                    An error "Read mismatch error" will occur if a read operation 
*                    is performed before doing a write operation. This is because the IIC  
*                    the IIC master application compares the received data with the 
*                    last data written.
*
*                  7. To perform the test with external slave device, Press switch SW1.
*                     The display will show "External (0x60)".   
*                
***********************************************************************************************************************/
