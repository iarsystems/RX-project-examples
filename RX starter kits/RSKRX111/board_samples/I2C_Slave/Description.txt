* File Name     : Description.txt
* Device        : R5F51115AxFM
* Tool-Chain    : RX Family C Compiler 1.2.1.0
* H/W Platform  : RSKRX111
* Note          : Application Leading Tool (Applilet) is used to generate code 
*                 for this sample program.  The name Applilet is used hereafter.
*                 The Applilet details and version number are given in the file 
*                 header for each relevant module.
* Description   : Demonstrates usage of the IIC unit in slave mode, by simulating
*                 an R1EX24xxx series EEPROM device (accessible via IIC Master 
*                 sample code) using a 7bit address 0x60 to avoid clashing with
*                 onboard EEPROM which uses the more standard 0xA0 address
*                 Can connect to external I2C master from the application
*                 header JA1:
*                 SDA : JA1 pin 25
*                 SCL : JA1 pin 26
*                 0V  : JA1 pin 2 or 4
* Operation     :   1. Compile and download the sample code to the target. 
*                      Click the 'Resume' icon on the toolbar to 
*                      start the software.
*                    
*                   2. Observe the LCD display - the R5F51115AxFM CPU will 
*                      display an introduction message
*                       
*                   3. The display will be updated when successful read and 
*                      writes have occurred.
