*                 for this sample program.  The name Applilet is used hereafter.

*                 measurement from pot RV1 to an array when triggered by SW1

*                      Click the 'Resume' icon on the toolbar to 
*                      start the software.
*                    
*                   2. Observe the LCD display - the R5F51115AxFM CPU will 
*                      display the values in the array in a grid format.
*                       
*                   3. Adjust the potentiometer, press SW1 to carry out a 
*                      12-bit A/D conversion of the ADC channel AN000 and 
*                      observe the value being placed into successive elements
*                      of the array.
