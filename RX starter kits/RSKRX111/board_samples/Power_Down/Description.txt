/***********************************************************************************************************************
* File Name    : Description.txt
* Version      : 1.0
* Device(s)    : R5F51115AxFM
* Tool-Chain   : CCRX
* H/W Platform : RSKRX111
* Note         : Application Leading Tool (Applilet) is used to generate code 
*                for this sample program.  The name Applilet is used hereafter.
*                The Applilet details and version number are given in the file 
*                header for each relevant module.
* Description  : This sample demonstrates usage of power down modes, using
*                RSK switches to send the system into one of the three power down modes.
*                The power down modes are:
*                                   Sleep Mode
*                                   Deep Sleep Mode
*                                   Software Standby Mode
*                 
* Operation    : 
*                 1. Compile and download the sample code. Click the 'Debug Icon' 
*                    button to start program execution. Click again if the program
*                    stops at Main.
*
*                 2. The LCD will display "Power Down".
*
*                 3. Press SW1, to set the MCU into sleep mode. The LCD will 
*                    display "Sleep Mode".
*
*                 4. Press any key to wakeup from the sleep mode.  
*                    The "Sleep Mode" message will be cleared. 
*
*                 5. Press SW2, to set the MCU into deep sleep mode. The LCD will 
*                    display "Deep Sleep Mode".
*
*                 6. Press any key to wakeup from the deep sleep mode. 
*                    The "Deep Sleep Mode" message will be cleared. 
*                
*                 7. Press SW3, to set the MCU into software standby mode. The LCD will 
*                    display "Standby Mode".
*
*                 8. Press any key to wakeup from the software standby mode. 
*                    The "Standby Mode" message will be cleared. 
*
* Note          : By removing R102, and fitting an ammeter across J8; it is 
*                 possible to observe the current consumption as the MCU
*                 switches between normal and power down modes.
*                
***********************************************************************************************************************/
