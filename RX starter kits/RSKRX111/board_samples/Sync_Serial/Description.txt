/***********************************************************************************************************************
* File Name    : Description.txt
* Version      : 1.0
* Device(s)    : R5F51115AxFM
* Tool-Chain   : CCRX
* H/W Platform : RSKRX111
* Note         : Application Leading Tool (Applilet) is used to generate code 
*                for this sample program.  The name Applilet is used hereafter.
*                The Applilet details and version number are given in the file 
*                header for each relevant module.
* Description  : This sample demonstrates usage of the SCI unit in synchronous
*                mode by performing a loop back test between two SCI channels.
*
* Modification : Remove R111, R122, R116 and R224.
*                Fit R192 and R195.
*                Ensure Link J11 is connected between 1 - 2.
*
* Wire Connections:
*                 JA2, pin 10 (SCK1) to JA6, pin 11 (SCK12)
*                 JA2, pin 8  (RXD1) to JA6, pin 9  (TXD12)
*                 JA2, pin 6  (TXD1) to JA6, pin 12 (RXD12)
*
* Operation    : 
*                 1. Compile and download the sample code. 
*
*                 2. Double click the variable g_sci1_rx_buffer and drag it into
*                    the Expressions window, and do the same for the variables
*                    g_sci12_tx_buffer, g_sci1_tx_buffer and g_sci12_rx_buffer.
*                    From the Expressions window, right-click on the buffers
*                    and select 'Real Time Refresh'.

*                 3. Click the 'Debug Icon' button to start program execution. 
*                    Click again if the program stops at Main. The name of the
*                    sample will be displayed on the debug LCD. 
*                    
*                 4. The sample will then begin the data transfer. When the SCI
*                    activity is complete, the debug LCD will display either
*                    "Success" or "Failure".
*                   
*                 5. You can observe that the contents of g_sci1_rx_buffer have
*                    filled with the contents of g_sci12_tx_buffer. Likewise the
*                    contents of g_sci12_rx_buffer have been filled with that of
*                    g_sci1_tx_buffer.
*                   
*                 6. If the debug LCD reports "Failure", or shows "RX/TX" 
*                    without changing; check the configuration specified is set
*                    and click "Restart" to start again.
*                
*                
***********************************************************************************************************************/
