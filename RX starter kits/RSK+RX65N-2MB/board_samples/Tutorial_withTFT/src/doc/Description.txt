/***********************************************************************************************************************
* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F565NEDxFC
* Tool-Chain              : CC-RX V2.07.00
* Development environment : Renesas e2 studio
* Version                 : Renesas Smart Configurator V1.2.0
* H/W Platform            : RSK+RX65N-2MB
*
* Description  : This sample project is a project in which TFT display code for adding Graphic LCD contoroller feature
*                of RX65N to Tutorial project was added.
*
* Note         : Smart Configurator is used to generate code for this sample program. 
*                The Smart Configurator details and version number are given in the file 
*                header for each relevant module.
*
* Operating Procedure:  
*                For details of Building and Downloading the sample code refer to the RSK+RX65N-2MB Tutorial Manual 
*                (r20ut3892eg0100-rsk+rx65n-2mb-tutorialmanual.pdf).
*
*             1. To activate the TFT display module on the RSK+, change the DIP switch SW4 on the RSK+ as follows.
*
*                SW4 Pin.1 = OFF
*                SW4 Pin.2 = OFF
*                SW4 Pin.3 = OFF
*                SW4 Pin.4 = ON
*
*             2. Connect the RSK+'s G1CUSB0 port to a PC using a USB Type A to mini B cable.
*                The first time this port is connected to the PC an 'Installing Device Driver Software'
*                pop-up will appear and the driver will be automatically installed. In Device Manager, the virtual
*                COM port will appear under 'Port (COM & LPT)' as 'RSK USB Serial Port (COMx)', 
*                where x is a number.
*                
*             3. Open a terminal program (e.g HyperTerminal) on the virtual COMx port created in step 1. 
*                Ensure the terminal program connection settings are as follows:
*                
*                Baud Rate.............19200
*                Data Bits.................8
*                Parity.................None
*                Stop Bits.................1
*                Flow Control...........None
*
*             4. Compile and download the sample code. Click the 'Resume' button to start program execution.
*                Click 'Resume' again if the program stops at main().
*                The LCD display will show 'RSK+RX65N-2MB Tutorial Press Any Switch' on the first 3 lines of the LCD.
*                
*             5. The TFT display module will show the picture of board and debugger.
*               
*             6. Press any switch or the character 'C' in the terminal window. An A/D conversion will be performed. 
*                The result will be displayed in the center of the LCD.  The result and count will also be 
*                displayed in the terminal program. 
*                
*             7. Adjust the potentiometer RV1 and repeat step 6.
*
***********************************************************************************************************************/
