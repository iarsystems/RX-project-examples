* System Requirements: 
* Device(s)               : R5F565NEDxFC
* Tool-Chain              : CC-RX V2.07.00
* Development environment : Renesas e2 studio
* Version                 : Renesas Smart Configurator V1.2.0
* H/W Platform            : RSK+RX65N-2MB
*
* Description  : Demonstrates usage of the Real Time Clock (RTC) running from the 32.768 KHz sub-clock oscillator.
*                The RTC includes an alarm feature, set for 12.00 pm.
*
* Note         : Smart Configurator is used to generate code for this sample program.
*                The Smart Configurator details and version number are given in the file 
*                header for each relevant module.
*
* Operating Procedure:  
*                For details of Building and Downloading the sample code refer to the RSK+RX65N-2MB Tutorial Manual 
*                (r20ut3892eg0100-rsk+rx65n-2mb-tutorialmanual.pdf).
*
*             1. Compile and download the sample code. Click the 'Resume' button to start program execution.
*                Click 'Resume' again if the program stops at main().
*                
*             2. Observe the 12-hour digital clock on the LCD.  at 12:00pm the alarm interrupt will be activated and
*                'ALARM' will be flashed in the 4th line of the LCD. LED1 will also flash for a period of up to 
*                30 seconds or until switch SW1 is pressed.
*
***********************************************************************************************************************/
