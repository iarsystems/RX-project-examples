/***********************************************************************************************************************
* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F56609HxFB
* Tool-Chain              : CC-RX V3.04.00
* Development environment : Renesas CS+ V8.08.00
* Version                 : Renesas Smart Configurator V2.14.0
* H/W Platform            : RSKRX660
*
* Description  : Demonstration of the SCI in asynchronous mode. The program communicates from the RX660 
*                to a terminal program via an SCI channel and RS-232 via the on-board virtual USB COM port.
*
* Note         : Smart Configurator is used to generate code for this sample program.
*                The Smart Configurator details and version number are given in the file 
*                header for each relevant module.
*
* Operating Procedure:
*             1. Fit the PMOD LCD display to the board.  Ensure all the pins of the connector are correctly inserted 
*                in the socket.
*
*             2. Connect the E2 Lite Debugger to a free USB port on your computer. Connect the E2 Lite Debugger to the 
*                target hardware ensuring that it is plugged into the connector marked 'E2 Lite'.
*
*             3. Connect the RSK's G1CUSB0 port to a PC using a USB Type A to mini B cable. The first time this port
*                is connected to the PC an 'Installing Device Driver Software' pop-up will appear and the driver will 
*                be automatically installed. In Device Manager, the virtual COM port will appear under 
*                'Port (COM & LPT)' as 'RSK USB Serial Port (COMx)', where x is a number.
*                
*             4. Open a terminal program (e.g Tera Term) on the virtual COMx port created in step 4. 
*                Ensure the terminal program connection settings are as follows:
*                
*                Baud Rate.............19200
*                Data Bits.................8
*                Parity.................None
*                Stop Bits.................1
*                Flow Control...........None
*
*             5. Compile and download the sample code. Click the 'Go' button to start program execution.
*                The LCD display will show 'Asynchronous Serial Comms'.
*                
*             6. Observe the output on the terminal window. The numbers 0 to 9 will appear repeatedly. Type 'z' 
*                (lowercase) into the terminal to pause the number outputs, and any other key to resume.
*                
*             7. While data is being transmitted, LED0 will be ON and LED1 will be OFF. 
*                When transmission is inactive, LED0 will be OFF and LED1 will be turned ON.
*
***********************************************************************************************************************/
