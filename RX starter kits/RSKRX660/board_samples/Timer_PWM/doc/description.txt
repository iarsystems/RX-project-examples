/***********************************************************************************************************************
* File Name    : description.txt
*
* System Requirements: 
* Device(s)               : R5F56609HxFB
* Tool-Chain              : CC-RX V3.04.00
* Development environment : Renesas CS+ V8.08.00
* Version                 : Renesas Smart Configurator V2.14.0
* H/W Platform            : RSKRX660
*
* Description  : This sample uses channel 0 of the MTU1 to output a 1KHz PWM square waveform on the MTIOC1B output pin.
*
* Note         : Smart Configurator is used to generate code for this sample program.
*                The Smart Configurator details and version number are given in the file 
*                header for each relevant module.
*
* Operating Procedure:
*             1. Fit the PMOD LCD display to the board.  Ensure all the pins of the connector are correctly inserted 
*                in the socket.
*
*             2. Connect the E2 Lite Debugger to a free USB port on your computer. Connect the E2 Lite Debugger to the 
*                target hardware ensuring that it is plugged into the connector marked 'E2 Lite'.
*
*             3. Connect an oscilloscope probe to LED0.
*                Refer to section 3.3 of the RSKRX660 User Manual (r20ut5017eg0100-rskrx660-usermanual.pdf) for
*                details on component placement.
*
*             4. Compile and download the sample code. Click the 'Go' button to start program execution.
*
*             5. A 1KHz PWM output increasing from 10% to 90% then stepping
*                back to 10% will be displayed on the oscilloscope.
*
*             6. Press SW1 to stop the duty to cycle modulation and display the duty as a percentage.
*                Observe the static waveform on the oscilloscope.
*
*             7. Press SW1 to continue duty to cycle modulation. Observe the waveform's duty cycle varying.
*
***********************************************************************************************************************/
