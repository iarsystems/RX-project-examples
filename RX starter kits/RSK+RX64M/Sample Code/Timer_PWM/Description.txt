* Description  : This sample uses channel 2 of the MTU3 to output a 1KHz PWM 
*                square waveform on the MTIOC2A output pin. 
* Note         : Code Generator is used to generate code for this sample program. 
*                The Code Generator details and version number are given in the file 
*                header for each relevant module.
*
* Operation    : Power the RSK from a +5V centre positive PSU via the PWR connector.
*
* Instructions :  1. Connect an oscilloscope probe to R281. 
*
*                 2. Compile and download the sample code. Click the 'Go' button to start program execution from main.
*
*                 3. A 1KHz PWM output increasing from 10% to 90% then stepping
*                    back to 10% will be displayed on the oscilloscope. The 
*                    signal can also be seen on LED2.
*
*                 4. Press SW1 to stop the duty cycle modulation and display 
*                    the duty as a percentage. Observe the static waveform on 
*                    the oscilloscope.
*
*                 5. Press SW2 to continue duty cycle modulation.Observe the  
*                    waveform's duty cycle varying.
