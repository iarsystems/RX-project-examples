/***********************************************************************************************************************
* Project      : Low_Power_Mode
* File Name    : Description.txt
* Version      : Code Generator for RX64M V1.00.01.01 [09 May 2014]
* Device(s)    : R5F564MLCxFC
* Tool-Chain   : IAR Embedded Workbench
* H/W Platform : RSKRX64M
* Description  : Demonstrates the low power modes SLEEP, SW STANDBY and DEEP SW STANDBY for reducing current consumption.
*                
*                NORMAL - Normal operation with peripheral operation and all clocks running.
* 
*                SLEEP - In sleep mode, the CPU stops operating but the contents of its internal registers are retained. 
*                Other peripheral functions do not stop.  When the WDT is used, the WDT stops counting when sleep mode is
*                entered..
*                
*                SW STANDBY - In this mode, the CPU, on-chip peripheral functions, and all the oscillator
*                functions stop. However, the contents of the CPU internal registers, RAM data, on-chip peripheral functions, 
*                states of the I/O ports are retained..
*
*                DEEP SW STANDBY - in deep software standby mode, the CPU, internal peripheral modulessuspend/resume 
*                (except for parts of the RTC alarm, RTC interval, SCL2-DS, SDA2-DS, CRX1-DS, and USB suspend/resume 
*                detecting unit), RAM (except for standby RAM), and all functions of the oscillators are stopped; 
*                furthermore, since the internal supply of power for these modules is stopped, power consumption is markedly
*                reduced. At this time, the contents of all the registers of the CPU and internal peripheral modules
*                (except for parts of the RTC alarm, RTC interval, SCL2-DS, SDA2-DS, CRX1-DS, and USB suspend/resume
*                detecting unit) become undefined.
*
* Note         : Code Generator is used to generate code for this sample program. 
*                The Code Generator details and version number are given in the file 
*                header for each relevant module.
* Modifications: 
*
*                External Device/Component
*                -------------------------
*                Remove R217 and connect an ammeter across J21, configure the ammeter for current measurement.
*                NOTE: Use of the ammeter autorange function may cause large resistive loads to be 
*                inserted in the power supply to the microcontroller, causing CPU under voltage on the supply rails
*                and a reset when the MCU comes out of SLEEP mode. For this reason, do not use the ammeter autorange 
*                function and be sure to switch the ammeter back to the mA range before coming out of SLEEP mode
*                
* Operation    : Power the RSK from a +5V centre positive PSU via the PWR connector.
*
* Instructions : 
*             1. Compile and download the sample code. Click the 'Go' button to start program execution from main.
*                Press 'Stop Debugging' and disconnect the debugger from the RSK+ E1 connector. 
*                
*             2. The hardware platform and sample name will be displayed in the first two lines of the LCD display.
*                A real time clock will be displayed in the format: HH:MM:SS on the 3rd line of the LCD display.
*                'Normal Mode' will be displayed on the 4th line of the LCD display.
*                The clock is updated when the device is in normal operating mode.

*             3. The sample code will cycle through the different operating modes on each 
*                switch press starting with Normal, SLEEP, Normal, SW STANDBY, Normal then DEEP SW STANDBY. 
*                
*             4. Press SW1 to enter SLEEP mode, 'Sleep Mode' will be displayed on the LCD. 
*                Observe the current for SLEEP mode.  Press SW1 again to return to Normal mode.
*
*             5. Press SW1 to enter SW STANDBY mode, 'SW Standby Mode' will be displayed on the LCD. 
*                Observe the current for SW STANDBY mode.  Press SW1 again to return to Normal mode.
*                   
*             6. Press SW1 to enter DEEP SW STANDBY mode, 'Deep SW Standby Mode' will be displayed on the LCD. 
*                Observe the current for DEEP SW STANDBY mode. 
*                   
*             7. Press RESET to exit DEEP SW STANDBY  mode and go to step 2 to repeat the test.
*
