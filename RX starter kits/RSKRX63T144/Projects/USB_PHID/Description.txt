/***********************************************************************************************************************
* Project      : USB_PHID
* Version      : 1.00
* Device(s)    : R5F563TE
* Tool-Chain   : RX Family C Compiler 1.2.1.0
* H/W Platform : RSKRX63T144
*
* Description  : This sample demonstrates the use of the RX63T144 as a USB 
*                Peripheral HID . It can be configured as a HID Keyboard,
*                HID Mouse or in HID demo mode.
*
* Operation    : Ensure the RSK is configured as a bus-powered USB Peripheral.
*                Ensure that J10 pins 2-3 are shorted for slave mode.
*                Power the RSK from a PC USB type-A to type-B mini cable via the USB0_2 connector.
*
*                Configure the code for the required mode by uncommenting out 
*                one of the following lines from r_usb_class_usrcfg.h (src\HIDFW\include):
*
*       //#define USB_PHID_APL_MODE       USB_PHID_DEMO_MODE      /* Peripheral HID Application demo mode */
*       //#define USB_PHID_APL_MODE       USB_PHID_KEYBOARD_MODE  /* Peripheral HID Application keyboard mode */
*       #define USB_PHID_APL_MODE       USB_PHID_MOUSE_MODE     /* Peripheral HID Application mouse mode */
*
*
* Instructions (USB_PHID_DEMO_MODE): 
*             1. Compile the sample code and download to the RSK. Click the 'Restart' 
*                button to start program execution.
*
*             2. 'USB DEM ATTACH' should be displayed on the LCD.
*               
*             3. Launch the RSK_HID.exe application. Click the 'Connect' button and use VID = 0x0000
*                and PID = 0x0003.  The application should display a message indicating a successful
*                connection to the RSK.
*
*             4. Use the 'Toggle LED', 'ReadADC' and 'Set LCD' buttons on the RSK_HID.exe application to 
*                interact with the device.
*
* Instructions (USB_PHID_KEYBOARD_MODE): 
*             1. Compile the sample code and download to the RSK. Click the 'Restart' 
*                button to start program execution.
*
*             2. 'USB KBD ATTACH' should be displayed on the LCD.
*               
*             3. Launch the Windows Notepad application or any simple text editor. Pressing SW2 should
*                result in the program sending HID reports for characters 'a' to 'z' when pressed repeatedly.
*                Pressing SW3 should result in the program sending HID reports for numbers  '1' to '0' when 
*                pressed repeatedly.
*
* Instructions (USB_PHID_MOUSE_MODE): 
*             1. Compile the sample code and download to the RSK. Click the 'Restart' 
*                button to start program execution.
*
*             2. 'USB MSE ATTACH' should be displayed on the LCD.
*               
*             3. Use RSK SW2 to move the Windows mouse pointer up/down and SW3 to move it left/right.
*                Use SW2 and SW3 pushed simultaneously for left mouse button click.
*
***********************************************************************************************************************/
