* Project      : USB_HMSC
* Version      : 1.00
* Device(s)    : R5F563TE
* Tool-Chain   : RX Family C Compiler 1.2.1.0
* H/W Platform : RSKRX63T144
*
* Description  : This sample demonstrates the use of the RX63T144 as a USB 
*                Host acting as a Mass Storage Controller.
*
* Operation    : Ensure the RSK is configured as a self-powered USB Host.
*                Short pins 1-2 of J10 to set the board in Host mode.
*                Fit Resistors R110 (0R) and R126 (0R). 
*
* Instructions: 
*             1. Compile the sample code and download to the RSK. Click the 'Restart' 
*                button to start program execution.
*
*             2. 'USB HMSC Appstart' should be displayed on the LCD.
*               
*             3. Plug a USB stick into the host connector USB0_1 on the RSK.
*                If the USB stick is detected, 'MSC DEMO READY' will be displayed. 
*                If the USB stick is unrecognised, then 'ATTACH' will be displayed.
*
*             4. Press SW2 to write a test file to the USB stick. "MSC DEMO START" should 
*                be displayed on the LCD and LEDs 0, 1 and 2 should perform a flash cycle
*                as the file is continually written to the USB stick.
*
*             5. Press SW2 again to stop writing the file. "MSC DEMO STOP" should 
*                be displayed on the LCD and the LEDs should stop the flash cycle.
*
*             6. Disconnect the USB stick from the RSK. 'DETACH' should be displayed on the LCD.
*
*             7. Plug the USB stick into a PC. The stick will contain a file called HMSCDEMO.txt
*                which contains all the ASCII set characters.
***********************************************************************************************************************/
