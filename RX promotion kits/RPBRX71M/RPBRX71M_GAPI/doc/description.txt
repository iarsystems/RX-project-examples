1. Before Use

  This sample program has been written for and tested on the RPB RX71M
  target board.

  ****************************** CAUTION ******************************
   This sample program is for reference only. Please use this sample 
   program for technical reference.
  ****************************** CAUTION ******************************
  
2.  System Requirements 
  The system requirements for this sample program are listed below.
  
 Device(s)               : R5F571MLCDFP 
 H/W Platform            : RPB RX71M
 Tool-Chain              : CC-RX 
                           Version 2.05
 Development environment : Renesas e2 studio
                           Version 5.1
 Application Note        : R20UT3803EG RX71M Revelation Kit User's Manual
 GAPI User's Manual      : R21UT0231EG Renesas GAPI Graphics API User's Manual

 3. Description           
                           This project demonstrates the capabilities of the RPB RX71M 
			   with a number of Graphical User Interface simulations
                           using the Renesas Graphics API.

 4. Operating Conditions 
	Ensure SW2 is set as follows:
                          SW2 - Position 1 - ON
                                Position 2 - OFF

 5. Operating Procedure     

 Use the following procedure to execute this sample program.
                   1) Connect the USB cable between CN9 'Debug' of the RPB RX71M to 
                      the development PC.

                   2) Start the integrated development environment, e2 studio.
                      Import the project [RPBRX71M_GAPI] into a workspace.

                   3) Build the [RPBRX71M_GAPI] project using the HardwareDebugRPBRX71M
                      build configuration.
                   
                   4) Start a debug session using the [HardwareDebug]
                      debug configuration.
                       
                   5) Run the demonstration by using the 'Resume' menu command.             

                   For details of operating the sample refer to the User's Manual.
