FPU Bouncing Balls Demo

The RX62N VNC server is now configured to run the FPU Bouncing Balls demo. Use a VNC client and connect over port 5900 to the RX62N demo board.
The FPU Bouncing Balls demo can be viewed on the VNC client. The demo was developed using realVNC (www.realvnc.com).

The green ball represents the FPU calculated position.

The red ball represents the non-FPU calculated position.
