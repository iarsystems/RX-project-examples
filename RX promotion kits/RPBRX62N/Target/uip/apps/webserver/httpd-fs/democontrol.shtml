LED Control

The RPBRX62N board has 3 user LEDs, labelled “LED0”, “LED1”, and “LED2”. Select for each of the three LEDs whether to switch it on or off, then press “Send”.

Click here to go to the LED control demo.

USB HID Mouse Emulation

The joystick on the RPBRX62N can be used as a USB HID Mouse on your PC. The RPBRX62N must be connected to your PC via USB for this to work. Press the “HID Mouse Emulation On” button, the mouse pointer on your PC will now move as you move the joystick on the RPBRX62N. The joystick centre works as a right-mouse button, and the SW1 button (next to the joystick) works as a left-mouse button.

Note that some of the other demos also use the joystick, and to avoid confusion it’s best to switch USBHID Mouse Emulation off when running the Mandelbrot Demo or the Pong Game.

Dhrystone benchmark

The Dhrystone benchmark is an industry standard benchmark developed originally in 1984 intended to be representative of system (integer) programming. To run the Dhrystone Demo, press the button below. The web page shown will refresh every 3 seconds, showing you the benchmark results of the previous invocation of the Dhrystone benchmark.
The Mandelbrot, Bouncing Ball, and Pong demo use a VNC client. These demos support 1 VNC connection, at port 5900. When switching from one demo to another (on the “Demo Control web page) the VNC connection remains alive and the newly chosen demo is displayed. A VNC client is not provided with this Renesas Promotional Board kit so you will need to download the VNC client of your choice from the internet. When developing the demo the realVNC client (www.realvnc.com) was used, but any VNC client should work and there are several freely available online.
To view the Mandelbrot, Bouncing Ball, or Pong Game demo, start the VNC client and connect to the same IP address as used with the web browser.

FPU versus non-FPU Bouncing Ball Demo

Start the VNC client, and press button below. If the VNC client is already running (displaying the Mandelbrot or Pong Game demo), the FPU (Bouncing Ball) demo will be displayed instead. The RPBRX62N demo program uses only one VNC connection.
The green ball represents the position calculated when using the FPU (Floating Point Unit, colloquially a math coprocessor). The red ball represents the position calculated when using floating point emulation.
