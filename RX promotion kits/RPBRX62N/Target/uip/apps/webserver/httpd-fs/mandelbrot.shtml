Mandelbrot Demo

The RPBRX62N VNC server is now configured to run the Mandelbrot demo. Use a VNC client and connect over port 5900 to the RX62N demo board.
The Mandelbrot demo can be viewed on the VNC client. The demo was developed using realVNC (www.realvnc.com).

Use the RPBRX62N joystick to move the crosshairs to a position to zoom into.

Click the RPBRX62N joystick center to zoom in.

Click the RPBRX62N SW1 to zoom out.
