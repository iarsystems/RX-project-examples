Renesas RX62N is running uIP stack

RX62N Features:

  • RX CPU Core – 100MHz (2.7 – 3.6V)
    • Enhanced Harvard Architecture
    • 165 DMIPS at 100MHz
    • Floating Point Unit (FPU)
    • Multiply Accumulate (MAC)
  • Low Power Consumption
    • 500 uA per MHz, all peripherals active
    • 19 uA Deep Standby with RTC running
  • Flash Memory
    • 100 MHz, zero wait-state access
  • Analog
    • 8 channels 12-bit ADC, 1 ms conversion time
    • 2 channels 10-bit DAC
  • Timers
    • Specialized for motor control, plus standard timers
  • USB Full Speed Host or Device
    • 2 channels (BGA176), either can be host or device
    • PHY included for both USB channels
    • OTG operation with external Vbus switch
  • Ethernet MAC, 10/100 full/half Duplex
    • Supports Xmit and Rcv IEEE-802.3 frames
    • 2KB SRAM buffers for xmit & recv w/DMA support
    • Supports MII and RMII to external PHY
  • CAN Interface with 32 Mailboxes
  • Control colour TFT-LCD up to WQVGA resolution
  • Package as small as 13 x 13 mm
