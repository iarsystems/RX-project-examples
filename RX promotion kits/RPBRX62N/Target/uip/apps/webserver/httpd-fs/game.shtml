Game

The RPBRX62N VNC server is now configured to run the Game. Use a VNC client and connect over port 5900 to the RX62N demo board.
The Game can be played using the VNC client and the RPBRX62N demo board's joystick (SW2 on the RPBRX62N board). The demo was developed using realVNC (www.realvnc.com).

Move the paddles up and down using the RPBRX62N joystick,

Click the joystick center to start the game.

After a point is scored, click the joystick center to restart the game.

The ball starts with a random speed in a random direction.

Good luck!
