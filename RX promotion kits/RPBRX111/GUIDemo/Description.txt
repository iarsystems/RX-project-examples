/*******************************************************************************
* File Name     : Description.txt
* Version       : 1.00
* Device        : R5F51115ADFM
* Tool Chain    : EWRX v2.42
* H/W Platform  : RPBRX111
* Description   : Demonstrates features of the RX111 by interacting with a
*                 graphical interface running on a PC.
*
* CAUTION       : Driving PA0_LDOEN low will turn off the Power Supply to the
*                 RX111. Only do this if you intend to supply power externally 
*                 via VCC_HARVEST on CN7 pin 5.  Refer to the Troubleshooting 
*                 section in the Design Manual to recover from this state.
*
* Operation     :   1. Compile and download the sample code to the target. 
*                      Stop the debugger but leave the USB cable plugged in.
*
*                   2. Launch the 'RX111Demonstrator.exe' application.
*
*                   3. From the 'Home' tab click 'Connect'. 
*
*                   4. The three GUI tabs provide options to view the MCU 
*                      current consumption (Power Measurement), switch between
*                      operating and sleep modes (Low Power).
*
* Notes         :   1. Further information about the GUI can be found in the 
*                      tutorial Manual provided with the RPB.
*                   2. Application Leading Tool (Applilet) is used to generate  
*                      code for this sample program. The name Applilet is used 
*                      hereafter. The Applilet details and version number are  
*                      given in the file header for each relevant module.
