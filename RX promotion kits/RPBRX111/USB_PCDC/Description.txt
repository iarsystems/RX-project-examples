/*******************************************************************************
* File Name     : Description.txt
* Version       : 1.00
* Device        : R5F51115ADFM
* Tool Chain    : EWRX v2.42
* H/W Platform  : RPBRX111
* Description   : This sample demonstrates the use of the RX111 as a USB
*                 peripheral using the CDC Abstract Model for serial port
*                 emulation.
*
* CAUTION       : Driving PA0_LDOEN low will turn off the Power Supply to the
*                 RX111. Only do this if you intend to supply power externally 
*                 via VCC_HARVEST on CN7 pin 5.  Refer to the Troubleshooting 
*                 section in the Design Manual to recover from this state.
*
* Operation     :   1. Compile and download the sample code to the target. 
*                      Click the 'Go' icon to start program execution.
*
*                   2. Connect a mini-USB cable to CN1 and a Windows PC. The RPB
*                      will be detected.
*
*                   3. The first time the connection is made a Windows driver
*                      must be installed. 
*                       a. Open Windows Device Manager and locate the device
*                          'CDC USB Demonstration', which should be marked with
*                          an exclamation mark.
*                       b. Right-click and select 'Update Driver Software' and
*                          'Browse my computer for driver software'. Browse to
*                          the cdc_inf folder provided with this sample and
*                          click 'Next'.
*                       c. Select 'Install this driver anyway'. The driver 
*                          should install successfully and be shown in Device 
*                          Manager under Port '(COM & LPT)->CDC USB Demonstration
*                          (COMX)' where X is a number in the range 1 - 99.
*
*                   4. Use a terminal emulation program such as Hyperterminal,
*                      Teraterm or PuTTY and connect to COMX using 19200 baud,
*                      8-bit data, no parity and 1 stop bit.
*
*                   5. Press any key to connect to the program and display a 
*                      welcome message. Type into the terminal window and 
*                      observe that the characters are echoed back by the RPB.
*******************************************************************************/
