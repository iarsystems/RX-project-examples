/*******************************************************************************
* File Name     : Description.txt
* Version       : 1.00
* Device        : R5F51115ADFM
* Tool Chain    : EWRX v2.42
* H/W Platform  : RPBRX111
* Description   : Demonstrates power consumption in multiple clock modes, sleep
*                 states and for various CPU load levels.  Running this program
*                 under debugger control will affect measured current levels.
*                 To obtain currents stated in the Hardware Manual run this 
*                 program stand-alone without the debugger.
*
* Modifications : Current consumption in various low power modes can be measured 
*                 directly using an ammeter connected across JP1 and removing R64
*                 from the board.  Ensure that SW3 is in the OFF position.
*
* CAUTION       : Driving PA0_LDOEN low will turn off the Power Supply to the
*                 RX111. Only do this if you intend to supply power externally 
*                 via VCC_HARVEST on CN7 pin 5.  Refer to the Troubleshooting 
*                 section in the Design Manual to recover from this state.
*
* Operation     :   1. Compile and download the sample code to the target. 
*                      Stop the debugger and disconnect the USB cable.
*
*                   2. Connect an Ammeter across JP1 and select the mA range. 
*                      Connect a mini-USB cable to CN8 and a PC. LED0 - LED3 
*                      will flash several times.
*
*                   3. The demo provides a menu which is navigated by the
*                      potentiometer RV1 and selected by pressing SW1.
*                      Select a menu item based on the following list:
*                      +====================================================+
*                      |        MAIN MENU OPTIONS USER INTERFACE MENU       |
*                      +====================================================+
*                      | Adjust potentiometer RV1 then press SW1 to select. |
*                      | Corresponding value will be displayed on LEDs      |
*                      | using binary.                                      |
*                      |                    (msb)  LED2  LED1  LED0 (lsb)   |
*                      |   (0) RTC_MENU             0     0     0           |
*                      |   (1) SUB_32k              0     0     1           |
*                      |   (2) LOCO_4M              0     1     0           |
*                      |   (3) HOCO_32M             0     1     1           |
*                      |   (4) SW_SLEEP             1     0     0           |
*                      |   (5) DP_SLEEP             1     0     1           |
*                      |   (6) SW_STBY              1     1     0           |
*                      +----------------------------------------------------/
*
*                  4a. If option 0 was selected then the user should select
*                      a value for the RTC options:
*                      +====================================================+
*                      |            RTC OPTIONS USER INTERFACE MENU         |
*                      +====================================================+
*                      | Adjust potentiometer RV1 then press SW1 to select. |
*                      |                    (msb)  LED0  LED1  LED2 (lsb)   |
*                      |   (1) Output RTC           0     0     1           |
*                      |   (2) Reset RTC            0     1     0           |
*                      |   (3) Start RTC            0     1     1           |
*                      |   (4) Stop RTC             1     0     0           |
*                      +----------------------------------------------------/
*                      (will return to step 4 after selection)
*
*                  4b. Otherwise, a clock mode was selected. LED0 will flash
*                      the selected number of times to confirm the selection.
*
*                   6. The user must next select the CPU load option in the
*                      same way:
*                      +====================================================+
*                      |           CPU LOAD USER INTERFACE MENU             |
*                      +====================================================+
*                      | Adjust potentiometer RV1 then press SW1 to select. |
*                      |                    (msb)  LED2  LED1  LED0 (lsb)   |
*                      |   (1) CPU_MIN              0     0     1           |
*                      |   (2) CPU_TYP              0     1     0           |
*                      |   (3) CPU_MAX              0     1     1           |
*                      +----------------------------------------------------/
*
*                   7. LED1 will flash the selected number of times to confirm.
*
*                   8. At this point the CPU enters a full power loop in the 
*                      selected mode. LED2 will be lit. Observe the MCU current 
*                      measurement.
*
*                   9. Press SW1 to put the CPU into the selected low power
*                      mode and again observe the MCU current measurement. 
*                      Note for Modes 1-3 above normal sleep mode is activated
*                      at this point.  Note for Mode 1 (SUB_32k) and Mode 6 
*                      (SW_STBY) the current will be in the order of micro Amps,
*                      so it may be necessary at this point to switch the 
*                      Ammeter into the uA range.  Note that this introduces a 
*                      larger series resistance which will produce a significant
*                      voltage drop once the current returns to the mA range. 
*
*                  10. To exit the low power mode and restart, return the Ammeter
*                      to the mA range if necessary and press the reset switch.
*
*******************************************************************************/
